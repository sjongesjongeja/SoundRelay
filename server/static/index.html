Android App & USB Modus

1. Android App (Systeemgeluid streamen):
Installeer SoundRelay.apk op je telefoon. Deze app vangt al het interne geluid op (Spotify, YouTube, games, etc.) via Android's officiële AudioPlaybackCapture API en streamt het zonder kwaliteitsverlies met lage latency.

2. USB Kabel (0ms Latentie - Geen Wi-Fi nodig):
Sluit je telefoon aan via USB met USB-debugging ingeschakeld en voer usb_stream.bat uit. Dit stuurt audio direct via de kabel voor perfecte synchroniciteit bij gamen en video's!
